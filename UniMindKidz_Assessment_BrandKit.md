# Brand Kit — Skill Assessment Reference

## Colors (already used in the attached prototype's CSS `:root`)
- Navy (primary text/headers): `#33475B`
- Sun / warm accent: `#F3A93E`
- Sun Dark (accent shadow/hover): `#D6862A`
- Sky (secondary accent): `#6FC3E4`
- Grass (success/complete state): `#5DA377`
- Cream (background): `#FFF8EA`
- Coral (error/retry state): `#E86A55`

## Fonts
- Headers: **Baloo 2** (rounded, friendly — used for all `h1` and button text)
- Body text: **Nunito**
- Both loaded via Google Fonts in the attached file's `<head>`

## Tone
- Warm, calm, and encouraging — never rushed or high-pressure (no countdown timers, no "hurry up" language anywhere in the student-facing experience)
- Nervous-system-friendly pacing: slow breathing exercises, gentle transitions, no jarring sounds or flashing elements
- Simple, concrete language appropriate for early elementary readers/listeners

## What's included in the attached prototype excerpt
- One full day (Kindergarten, Week 1, Day 1: "Welcome to Our Class Family") with all five steps: meditation → story → discussion/check-in → reflection → completion badge
- The guide character "Sunny" (CSS-only rendering, no image assets)
- Browser text-to-speech narration wired to each screen — this is the piece Phase 1 replaces with real hosted audio
- A localStorage-based "mark complete" stand-in for the persistence layer

## What's intentionally NOT included
- The rest of the 90-day curriculum
- Other guide characters (owl, turtle, rabbit, etc. — used in other weeks)
- The multi-grade day-menu/browse system
- Any org- or product-identifying details beyond what's needed to complete the task

Please don't share this file or its contents outside of completing the assessment.
